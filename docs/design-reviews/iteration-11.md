## Топ-5 правок

1. Блокер, полоса камеры. `styles/scene.css:287` (блок `max-width: 1080px`) добавить
   `.scene-bar { position: static; order: 3; margin: 12px var(--gutter) 0; }` - полоса встаёт
   под сцену, как `.hud-progress` на карте (`responsive.css:108-114`). Либо в
   `pages/ScenePage.tsx:520` перенести полосу внутрь обёртки сцены с `position: relative`.
2. Блокер, галерея на узком экране. `styles/scene.css:467-475`: `inset: var(--inset)` ->
   `inset: calc(var(--inset) * 2 + var(--bar)) var(--inset) var(--inset)`, как на широком
   экране, либо `z-index` выше `.topbar` и `inert` на шапку, пока диалог открыт. Ловушка
   фокуса: `ShotGallery.tsx:106` - `<dialog>` с `showModal()` вместо `section role="dialog"`,
   тогда Tab не уходит на canvas.
3. Блокер, цвет кольца. `styles/scene.css:447-450`: `0 0 0 2px var(--warn)` -> тот же
   нейтральный прицел, что у выбранной посадки на карте (белое кольцо с тёмной обводкой
   `var(--ink)`), без цвета вердикта.
4. Номер посадки из данных, а не из адреса. `ScenePage.tsx:447` верит `?n=`: по ссылке с

   есть `id`) и брать оттуда; тогда и заголовок по клавише K (`ScenePage.tsx:407`) получит номер.

   Прогон 01a0dc98 сделан до правки `assign.py`: в карточке всё ещё «квота вида 10% выбрана»;
   перезапустить демо-прогон перед показом.
