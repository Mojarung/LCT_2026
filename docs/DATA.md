# Карта данных LCT_2026

Кейс: автоматическое проектирование озеленения улиц с учётом подземных сетей и городской среды. Вход — DXF участка, выход — DXF с посадками.

Всё из `data/` и `tools/` в git не идёт (`.gitignore`).

## Пилотный проект 20 улиц (внутренний zip)

4611 записей: 1008 dwg (2.6 ГБ), 372 pdf (4.2 ГБ), ~1900 фото jpg/heic (2.2 ГБ), 54 вложенных zip, xls/xlsx/docx.
**DXF в архиве нет ни одного** — всё DWG, конвертируем сами.

Типовая структура улицы (у разных улиц названия папок гуляют: «Исходные данные» / «ИСХОДНЫЕ ДАННЫЙ» / «Исходные данный»):

| Папка | Что внутри | Роль для нас |
|-------|-----------|--------------|
| `Исходные данные` | геоподоснова Мосгеотреста (xref'ы `3_ДЖКХ-2x_NNNNN{tp,up,kl,pp}`), ГП, дендроплан, перечётная ведомость, ДПиООС (pdf) | **вход** |
| `Проектное решение` | `Генплан.dwg`, `Посадочный план.dwg`, PDF-листы, паспорт объекта (ассортимент), ПЗ, «Деревья к удалению» | **эталонный ответ** проектировщиков |

## Как доставать данные

Распаковать одну улицу без фото (имена в zip в cp866):

```powershell
uv run --no-project python scripts/extract_street.py "16. улица Берзарина"
```

DWG → DXF (~70–110 с на файл 20–40 МБ, DXF в 3–5 раз больше DWG):

```powershell
tools\libredwg\dwg2dxf.exe -y -o out.dxf in.dwg
tools\libredwg\dwglayers.exe in.dwg     # быстрый список слоёв без конвертации (~7 с)
```

Читать DXF от LibreDWG только через `ezdxf.recover.readfile` — строгий `ezdxf.readfile` падает на битых многострочных строках. Стабильный LibreDWG 0.14 (2024) выдаёт нечитаемый DXF, нужен pre-release ≥0.14.8597.

## Табличные данные (Берзарина как образец)

- **Перечётная ведомость** (`Перечетка_*.xls`, лист «Перечетка»): №, порода, кол-во, диаметр (см, бывает «12-26» для многоствольных), высота (м), состояние, заключение (Сохранить / Удалить / Пересадить), компенсационная стоимость. № совпадает с выносками на дендроплане.
- **Паспорт объекта** (`Паспорт объекта *.xlsx`, лист «Описание»): проектный ассортимент — порода (рус + лат.), проектная высота, количество, особенности, декоративная функция; листы «Уход», «Календ план», «Тип план внес удобр».
- **Деревья к удалению** (`*.xlsx`): № по перечётке, порода, диаметр, высота, состояние, № фрагмента.
