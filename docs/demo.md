# Демонстрация: 8 минут

Сценарий 29.09.2026 для финального показа по ТЗ (разд. 4): вход с объекта пилота, расчёт с
учётом сетей, DXF с результатом на отдельных слоях, объяснение посадки с актом и пунктом,
проверка DXF в CAD под Linux, 3D-вид участка как бонус. Команды и адреса - разд. 5
документации (`docs/documentation/05-run.md`).

## Подготовка

На стенде с Linux и Docker, до показа:

```bash
docker compose up --build -d                   # образ green:latest, интерфейс и API на :8000
curl -s http://localhost:8000/api/v1/health
docker build -t green-cadcheck docker/cadcheck # LibreCAD 2.2 под Xvfb для проверки DXF
```

Датасет смонтирован в `./dataset` (каталог улиц `streets_oda`). Без датасета показ идёт на
встроенном фрагменте улицы Берзарина: окно 300 x 140 м настоящего чертежа пилота, 12 694
сущности. Заранее посчитать одну улицу каталога (Кустанайская, около 15 мин) и держать её
прогон открытым во второй вкладке: полная улица за время показа не досчитается.

## 0:00-1:00 - вход

Открыть `http://localhost:8000/`. Выбрать «Улица пилота» и Кустанайскую или нажать
«Запустить на встроенном участке». Профиль `strict`. Показать, что вход - DWG или DXF
Мосгеотреста с сетями, а параметры меняются в форме и попадают в `run_manifest.json`.

Фраза: «Сервис читает чертёж целиком и ведёт учёт каждого примитива. Чего не понял, не
считает грунтом и не разрешает для посадки».

## 1:00-3:00 - расчёт по нормам

Пока идёт фрагмент (около минуты), показать ход этапов поверх чертежа. Затем карту: газон и
асфальт по карте покрытий, сети, отказы у сетей красными метками, деревья и кустарник.

Проговорить логику:

- место дерева проверяется целиком: яма 2,2 x 2,2 м, 62 отступа до сетей, зданий, бортов и
  опор (СП 42.13330.2016, табл. 9.1; 743-ПП, табл. 3.6.1);
- шаг деревьев по взрослым кронам: в ряду аллеи 5 м (743-ПП, табл. 3.6.2, однорядная
  5-6 м), вне ряда - по кронам пары в вилке групповой посадки 5-7 м: боярышник 5 м, ель 6 м,
  липа 7 м. Две ели через 5 м проверку не пройдут;
- считается несколько полных вариантов плана, каждый проходит независимую проверку, из
  прошедших берётся лучший по индексу качества (`portfolio.json`, `quality.json`).

## 3:00-4:30 - объяснение посадки

Кликнуть дерево у сети. Карточка: вид и почему он, ближайшие нормы с выносками на карте,
фактический отступ против нормы, пункт акта. Кликнуть отказ: какая норма нарушена и на
сколько, при каком прикорневом барьере место было бы допустимо. Открыть «Отчёт
интерпретаций» (`report.html`): у каждой посадки определяющая норма с дословной цитатой.

## 4:30-6:00 - DXF в CAD под Linux

Скачать `result.dxf`. Проверка сохранности:

```bash
uv run green verify src/green/infrastructure/cad/samples/berzarina_fragment.dxf result.dxf
```

Открыть в LibreCAD из контейнера (разд. 5.6) или в nanoCAD: исходные слои на месте,
результат на слоях `GREEN_*`, их можно выключить независимо от подосновы. У каждой посадки
стоит цифра - номер позиции ведомости (текст на `GREEN_LABELS`), по нему вид находится в
ведомости справа от плана. LibreCAD эти цифры рисует, как и количества ведомости, коды правил
и номера пунктов, а русские слова показывает значками: в его штриховом шрифте нет
кириллицы. Скрытые атрибуты вставки (`POS`, `NUM`, `SPECIES`, `NPA`) LibreCAD не рисует: вид
и нормы каждой посадки - в `plantings.csv`.

## 6:00-7:00 - правка и повторный прогон

Перенести посадку мышью: сервис перемеряет нормы, перепроверяет план и показывает, прошёл
ли он проверку. Пересобрать DXF. Повторный прогон с другими параметрами:

```bash
curl -s -F "file=@src/green/infrastructure/cad/samples/berzarina_fragment.dxf" \
     -F "profile=strict" -F 'overrides={"crown_spacing": false}' \
     http://localhost:8000/api/v1/runs
```

## 7:00-8:00 - 3D-вид (бонус)

Кнопка «3D» на странице прогона: кроны по видам плана в выбранном возрасте, здания по
этажности из подписей, облёт улицы, сезон и погода, снимок PNG. Вид построен из того же
плана, что и DXF (`scene.json`).

## Что не обещать на показе

- зелёный статус проверки не удостоверяет отсутствие неизображённых сетей и качество
  грунта: он говорит, что план соблюдает нормы по данным чертежа;
- nanoCAD как таковой не проверялся, проверялся LibreCAD 2.2 под Ubuntu 26.04;
- полная улица считается минутами: от 1,4 до 33,1 мин, медиана 9,4 мин (прогон 29.09.2026 в
  Docker, разд. 8.2 документации).


## Существующие насаждения подосновы

Повторяющиеся кружки топографического знака не являются отдельными взрослыми деревьями. Распознанные кустарниковые полосы показаны непрерывно, размеры модели условные. Подробности и проверка на независимых улицах: [полосы растительности](vegetation-strips.md). Для результатов, полученных до исправления, нужен новый прогон исправленного встроенного участка.
