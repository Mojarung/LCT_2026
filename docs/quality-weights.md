# Веса индекса качества: как они получаются и как их проверить

Индекс качества плана (`docs/notes/29-quality-index.md`) - взвешенная сумма десяти слагаемых.
Ни один акт весов не задаёт, и «подобрать их перебором» не к чему: нет эталонных оценок
планов. Поэтому веса получаются так, как это делают для любых составных индексов, - по
методичке OECD/JRC (Handbook on Constructing Composite Indicators, 2008). Источники, цитаты и
статусы проверки - `docs/plans/2026-09-22-quality-literature.md`.

## Что говорит методичка

- «Weights are essentially value judgements» (с. 31): веса - суждение, поэтому их берут у
  экспертов, а не выдумывают.
- Иерархия в два уровня (с. 31): при разных размерах групп равные веса слагаемых смещают веса
  групп. У нас четыре группы.
- Парные сравнения по шкале Саати 1-9, отношение согласованности CR < 0,1 (с. 97-98, со
  ссылкой на Saaty 1980).
- Проверка устойчивости Монте-Карло: все спорные решения разыгрываются разом, смотрят, как
  сдвигаются места (шаг 7, с. 117-121).
- Слагаемое, которое на плане не определено, выпадает, веса остальных нормируются (с. 120) -
  так индекс и устроен.

## Группы

| Группа | Слагаемые | Вопрос | Вес сейчас |
|---|---|---|---|
| Надёжность | пригодность вида месту, категория МГСН В.6, запас до сетей | выживет ли посадка и устоит ли план при проверке на месте | 0,35 |
| Функции | тень, пылезащита, ярусность | что посадки дают улице (заказчик, QA:39) | 0,30 |
| Состав | разнообразие, ряды, сезонность | устойчивость к вредителям и облик | 0,20 |
| Объём | плотность МГСН В.1 | не мало ли посадок | 0,15 |

Порядок «объём ниже прочего» задал заказчик: «лучший вариант не самый плотный, а
функциональный» (`docs/notes/15-organizers-qa.md`, вопрос 11).

## Анкета эксперта: 15 суждений, 5-10 минут

Число - во сколько раз первое важнее второго: 1 - равно, 3 - умеренно, 5 - заметно, 7 -
сильно, 9 - абсолютно; 2, 4, 6, 8 - промежуточные. Если важнее второе - обратная величина
(1/3).

Группы (6 сравнений): надёжность / функции; надёжность / состав; надёжность / объём;
функции / состав; функции / объём; состав / объём.

Внутри групп (по 3): пригодность / категория, пригодность / запас, категория / запас; тень /
пылезащита, тень / ярусность, пылезащита / ярусность; разнообразие / ряды, разнообразие /
сезонность, ряды / сезонность.

Кого спрашивать (OECD, с. 96): заказчик ДПиООС; ландшафтные архитекторы и дендрологи;
эксплуатация («Жилищник», ГБУ «Автомобильные дороги»); желательно эколог. Члены команды
экспертами не считаются. Разумная панель - 5-8 человек.

## Как посчитать

Анкеты складываются в YAML (формат и пример - `docs/quality-ahp-example.yaml`), затем:

```
uv run python tools/quality_weights.py анкеты.yaml
```

Скрипт печатает веса каждого эксперта с CR, отбрасывает несогласованные анкеты (их надо
вернуть эксперту), сводит остальные геометрическим средним суждений и выдаёт строки
`quality_weights` для профиля. Математика - `src/green/application/quality/weights.py`,
тесты - `tests/test_quality_weights.py`.

Нынешние веса по умолчанию - черновик команды, а не суждение экспертов; пример анкеты,
который их воспроизводит, - `черновик-команды` в `docs/quality-ahp-example.yaml` (CR 0,022).

## Как проверить устойчивость

```
uv run python tools/research/quality_robustness.py --api http://127.0.0.1:8000
```

Берёт последний прогон каждой улицы и разыгрывает 2000 вариантов: схему весов (нынешние,
равные, ROC по порядку заказчика), возмущение весов групп x U(0,5; 1,5) и выпадение одного
слагаемого. Печатает средний сдвиг места R_S (OECD, ур. 38) и для каждой улицы медиану и
разброс её места. Критерий приёмки из ресерча: медианный сдвиг не больше 2 позиций.

Первый прогон на 17 улицах (индекс прошлой версии, 22.09.2026): медиана R_S 1,88, 95-й
процентиль 4,0. Индексы улиц близки (0,43-0,55), поэтому отдельные улицы ходят широко, и это
честный результат: по нему видно, какие места в рейтинге улиц вообще можно утверждать.

## Цели слагаемых и их источники

| Цель | Значение | Источник |
|---|---|---|
| Тень | полный балл с 75% потенциальной площади крон | Kenney, van Wassenaer, Satel 2011, с. 110, 114: «optimal» 75-100% |
| Запас до сетей | 0,5 м сверх нормы | СП 317.1325800.2017, п. 5.3.5.3: сети на плане 1:500 - до 0,5 м от натуры |
| Пылезащита | метр борта под кустарником - полностью, только под кроной дерева - x0,5; полный балл с 50% | Abhijith et al. 2017, с. 83: в уличном каньоне работает низкий сомкнутый ярус, кроны над дорогой ухудшают воздух у земли; 0,5 и 50% - параметры проекта |
| Разнообразие | 10 эффективных видов, квоты 10-20-30 | Santamour 1990; Jost 2006 (exp(H) - число видов); Galle et al. 2021 (у уличных реестров exp(H) 17-37) |
| Плотность | 150-180 деревьев и 600-720 кустарников на 1 км | МГСН 1.02-02, табл. В.1 |
| Штрафы, сезонность, нижняя ветвь плотности | 0,05 и линейные шкалы | источника нет - параметры проекта |
