# Проверка предложенного списка arXiv: CAD, нормы, layout и визуализация

[Актуальная карта использования статей](article_use_map_2026-09-15.md) показывает, какие идеи из 40 работ этого реестра нужны ближайшему этапу, какие отложены и какие исключены. Прежняя матрица 82 работ повреждена.

Проверено 15.09.2026 по страницам arXiv `/abs/<ID>`; для работ 2407.01928 и 2502.11065 также прочитан метод в полном тексте и официальный код. До этой проверки **ни одна из перечисленных 37 работ не использовалась явно** в [нашем реестре 40 работ](literature_register.md), старом сравнении методов или ICM. Есть *совпадение идей*: разделение семантики CAD/правил/оптимизации уже в продукте и ресерче, но это не ссылка на эти публикации. Уровень проверки отдельных строк ниже — первичный abstract/видимый метод; рейтинги означают практический приоритет **при нынешних 20 уличных CAD-пакетах**, а не оценку качества исследований.

**A** — стоит использовать для конкретного исследовательского/инженерного шага; **B** — полезный принцип при дополнительных данных/разметке; **C** — периферия или бонус; **D** — неподходящая модель для нынешнего ядра. Никакая работа не доказывает московский правовой статус места. Скрининг учитывает [исходное ТЗ и фактический вход](requirements_and_data.md): DXF→DXF, отдельные слои, неизменность подосновы, деревья/кустарники, проверенные сети/отступы/пункты НПА. `SurfaceMap` в `main` выводит материал из подписей/барьеров, но не обследует грунт.

## Решение после проверки

Наибольший практический потенциал имеют **не генераторы изображений**, а три узких исследования: (1) оценить, нужны ли layer+TEXT/line модели для *ошибок семантики, которые не решает текущий reader*, по ручным меткам на уличных topo; (2) собрать версионированный машиночитаемый корпус московских норм с точным объектом/измерением/пунктом, используя CODE-ACCORD/interpretability/RAG лишь как инструменты черновой разметки и поиска; (3) сравнить зональное размещение с ограниченной MILP/CP-SAT постановкой после подтверждения площадок. Для бонуса отдельно проверить diffusion по фото со строгой CAD/photo-привязкой. Сейчас **нет прямого готового веса, codebase или статьи**, которую можно взять и получить юридически и физически проверенный план посадок из нашего DXF.

Быстрый честный gate для SymPoint-V2: ручная разметка 2–3 разных топопланов, в том числе составных/пунктирных/текстовых объектов; train/holdout по **улице**, а не по фрагментам того же чертежа; метрики по существующим деревьям, газонным границам и сети, время/RAM на полном topo, сравнение с текущим слоёвым классификатором. Для MILP: один полный пакет заказа с XREF/координатами/проверенными поверхностью и нормами; одинаковый candidate set для зонального greedy и solver, результат в статусах `allowed/approval/unknown`, соблюдение демо-лимита и памяти. Это предложения испытаний, **не проведённые тесты этой задачи**.
