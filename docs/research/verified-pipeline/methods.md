# Выбор методов для неизвестных DXF

Проверка источников: 23.09.2026. Ниже отдельно указаны сведения авторов и наши
инженерные решения. Метрики чужих задач не переносятся на наши чертежи.

| Источник / уровень чтения | Полезный вывод | Решение для эксперимента |
|---|---|---|
| [ezdxf XREF](https://ezdxf.readthedocs.io/en/stable/xref.html), документация | Внешняя ссылка — блок с собственной вставкой; часть сущностей не поддерживается импортом | Сохранять преобразования и сообщать пропуски; проверять массивы, вложенность, неполные ссылки; импорт не означает семантическую полноту |
| [ezdxf INSERT](https://ezdxf.readthedocs.io/en/stable/blocks/insert.html), документация | `virtual_entities` раскрывает вставку, `multi_insert` раскрывает массив; callback сообщает непреобразованные сущности | Не заменять маленький блок точкой без семантического основания; тестировать перенос/поворот/масштаб и имена независимо |
| [SciPy MILP](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.milp.html), документация | Двоичные переменные, линейные ограничения, статус, primal/dual bound и gap | Сравнить greedy и MILP на одном наборе допустимых кандидатов. Глобальность относится только к этой дискретной модели |
| [Pinto, Russo, Sudoso 2025](https://arxiv.org/abs/2502.11065), аннотация | MILP для размещения NBS с несколькими целями, физическими ограничениями и справедливостью | Переносима форма «выбрать место/тип при ограничениях». Чужие городские экологические метрики не вычислять без входных данных |
| [Bodnaruk et al., Where to plant urban trees?](https://research.fs.usda.gov/treesearch/52880), карточка работы | Цели посадок могут конфликтовать; авторы сравнивают схемы по разным экосервисам | Отдельно показывать допустимость, количество, ритм, разнообразие и покрытие. Веса качества — настройки проекта, не доказанные нормы |
| [FloorPlanCAD](https://arxiv.org/abs/2105.07147), аннотация | Размеченные векторные планы и CNN/GCN для распознавания символов | Возможная архитектура семантической подсказки; набор классов планов зданий не соответствует подземным сетям нашего кейса |
| [SymPoint-V2](https://arxiv.org/abs/2407.01928), аннотация | Использует геометрию и информацию слоёв для panoptic symbol spotting | Кандидат на локальную модель после получения независимой разметки; переименование слоёв и новая схема обозначений должны войти в holdout |

## Что считается универсальностью

1. **Чтение:** одинаковая геометрия не должна зависеть от знакомого имени слоя,
   длины трубы или размера блока. Неподдерживаемое имеет диагностический след.
2. **Семантика:** источник класса известен (явное сопоставление, правило, гипотеза).
   Безымянная линия не даёт достаточных данных о типе сети. Геометрия может
   предлагать класс, но не удостоверяет его.
3. **Пригодность:** отсутствие асфальта в распознанных объектах не доказывает грунт.
   Явная зона/покрытие, подпись и предположение по дереву — разные виды свидетельств.
4. **Расстановка:** генератор независим от названий улиц. Смена начала координат,
   поворот участка и разрешение сетки входят в проверку устойчивости результата.
5. **Проверка:** повторная проверка окончательных координат/видов и контрпримеры,
   вычисленные полным перебором, не только повторный вызов генератора.

## Роль локальной модели

Нейросеть допустима как источник кандидатов семантики и оценок композиции.
До измерения ошибок на новых размеченных чертежах её вывод не будет основанием
для автоматического разрешения посадки. Сейчас нет проверенного набора меток
«этот объект действительно водопровод/газон» для неизвестных схем. Обучение на
метках нашего regex-классификатора измеряло бы воспроизведение его ошибок.
Сначала устраняются подтверждённые потери геометрии и ложная определённость.

## Матрица проверок

- Пустой файл, только текст, только один материал, противоречащие подписи.
- Линии/полилинии/дуги/сплайны/штриховки с отверстиями и разрывами.
- Поворот, отражение, метр/мм, дальнее начало координат, вставка массива.
- Вложенные, циклические, отсутствующие и неподдерживаемые блоки/XREF.
- Неизвестные имена слоёв, русские/латинские обозначения, ручное сопоставление.
- Нет границы/сетей/поверхности, частичное покрытие планшетами.
- Узкая полоса грунта, дерево в маленькой лунке посреди мощения, длинный разрыв борта.
- Разные диаметры труб, пересечения, равные расстояния, точка ровно на пороге.
- Совместимость окончательного вида с местом, кустарники рядом с деревьями,
  малые количества и квоты, отсутствие подходящего ассортимента.
- Ограничение времени solver, отсутствие допустимого решения, равные решения,
  воспроизводимость и сравнение с точным перебором на маленьких задачах.
