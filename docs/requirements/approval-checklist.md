# Что проверяет согласующий: чек-лист проекта озеленения улицы в Москве

Собрано 27.09.2026 двумя исследованиями: требования ТЗ и заказчика, требования актов и решения
ДПиООС из датасета. Пометки: **[текст]** - сверено по тексту акта или документа, **[опись]** -
по описи материалов улицы (`dataset/street_inventory`), **[вывод]** - наш вывод. Редакции:
743-ПП - ред. 05.06.2024 (в сервисе п. 3.6.1 по ред. 10.06.2026), 770-ПП - ред. 24.12.2024,
СП 82.13330 - ред. 27.12.2024, ГОСТ 21.508-2020, МГСН 1.02-02 с изменениями 2003 и 2006 годов.

## Первоисточник: решения ДПиООС по проектам пилота

В архиве датасета есть два решения ДПиООС:
- приостановка по Фрунзенской набережной от 25.05.2026 - PDF с текстом;
- отказ по Харьковскому проезду N 03450-2026 - скан.

По ним видно, за что проект возвращают:

1. Нет сравнительного баланса озеленения по объекту природного комплекса. Площадь озеленения
   должна быть не менее 70% или не меньше существующей. В ТЭП записки Фрунзенской было только
   «стало» **[текст]**.
2. Дендроплан и перечётная ведомость не по форме 770-ПП; все знаки легенды должны быть на
   чертеже **[текст]**, **[опись]**.
3. Нарушены отступы от сохраняемых деревьев (743-ПП, п. 9.8) **[текст]**.
4. Инвазивные деревья по 369-ПП назначены «сохранить» **[текст]**.
5. Пояснительная записка расходится с графикой **[текст]**.
6. Нет предложений по посадке взамен уничтожаемых, когда места есть **[текст]**.
7. Сорт и ком посадочного материала: например, сирень обыкновенную заменить сортовой с комом
   0,8 x 0,6 м **[текст]**.

Заказчик на сессии вопросов (`docs/notes/15-organizers-qa.md`) назвал главную причину
возврата - отступы, вторую - неверно посчитанные объёмы озеленения (вопрос 14).

## Показатели «было - стало», принятые в практике

- Итог перечётной ведомости по 770-ПП, прил. 3 **[текст]**:
  - деревья и кустарники в зоне работ: всего, сохранить, пересадить, вырубить;
  - высаживается по проекту;
  - газон: общая площадь, уничтожаемая площадь, создаваемая площадь.
- Проектировщики пилота показывают то же ведомостью баланса (Харьковская, Лодочная, 2-я
  Прядильная) **[опись]**. Пример Харьковской: 724 дерева в границе работ, 714 сохраняются,
  10 вырубаются, 10 высаживаются, газон восстанавливается на 31 307 м².
- Площадь крон и долю покрытия кронами в актах не нашли. Это показатель по вопросу 11
  заказчика (тень), а не норма **[вывод]**.
