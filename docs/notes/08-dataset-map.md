# Карта входных данных LCT_2026

Это навигация по пилотным файлам и эвристический список комплектов улиц, записанный 15.09.2026. Текущий локальный распакованный набор находится рядом с репозиторием, в `../Пилотный проект 20 улиц/` (20 папок проверены 16.09.2026); в Git чертежи не входят. Скрипты работы с архивом и CAD — `tools/`. Старое описание пути `repo/dataset/` было схемой для контейнера, не расположением файлов в этом workspace.

## Что считать входом и эталоном

| Часть папки улицы | Роль | Особенности |
|---|---|---|
| `Исходные данные` | Вход: геоподоснова, сети, граница, дендроизыскания и ведомости | Имена и наборы различаются; DWG может ссылаться на другие DWG через XREF |
| `Проектное решение` | Эталон проектировщика, не готовая разметка нормативно допустимых мест | Слои посадок и покрытия у команд различаются; нужен ручной нормоконтроль |
| Архивы, портфолио, фото | История и бонусная визуализация | Не подменяют CAD/почвенные данные для обязательного контура |

Первый просмотр архива оценил около 1008 путей `.dwg` и ошибочно не заметил исходный DXF. Локально подтверждён **один DXF**: `3. 3-я Парковая/Исходные данные/10001759_3-я Парковая ул/00_Ссылки/АСУ ОДХ/117861691400001.dxf`. Более точный [массовый скан](05-dwg-scan.md) различает 1009 путей, 190 служебных `PaxHeader`, **819 настоящих DWG**, 749 успешных конвертаций по исходным Windows-путям и 70 отказов из-за длинных путей. Нельзя называть все 819 успешно сконвертированными без переноса отказавших файлов на короткие пути и повторного полного прогона.

## Табличные данные (Берзарина как образец)

- **Перечётная ведомость** (`Перечетка_*.xls`, лист «Перечетка»): №, порода, кол-во, диаметр (см, бывает «12-26» для многоствольных), высота (м), состояние, заключение (Сохранить / Удалить / Пересадить), компенсационная стоимость. № совпадает с выносками на дендроплане.
- **Паспорт объекта** (`Паспорт объекта *.xlsx`, лист «Описание»): проектный ассортимент — порода (рус + лат.), проектная высота, количество, особенности, декоративная функция; листы «Уход», «Календ план», «Тип план внес удобр».
- **Деревья к удалению** (`*.xlsx`): № по перечётке, порода, диаметр, высота, состояние, № фрагмента.
