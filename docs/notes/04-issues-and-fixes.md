## Проверка каркаса по ТЗ (15.09.2026, вечер)

|---|---|---|

| На станции принимался первый допустимый отступ, даже если это «требует согласования», а дальше был отступ без замечаний | Логика `_Selector.flush` | Сначала перебираются отступы с вердиктом allowed, затем needs_approval |
| Лимит отказов срабатывал молча | `max_rejections` в профиле | Предупреждение в плане, когда лимит достигнут |
| Нет правила для трамвайных путей, хотя они есть в АСУ ОДХ (8.5 тыс. м²) | rules.yaml | Проектный отступ 5 м / 3 м (строка нормы не найдена, см. план) |
| Нет правила для ЛЭП, а ТЗ прямо называет охранные зоны ЛЭП | rules.yaml, слой «ЛЭП» на топоплане (1148 объектов на генплане) | Зона 2 м (ВЛ до 1 кВ) с вердиктом «требует согласования», ссылка на 160-ПП РФ, цитата не сверена |
| Слои топоплана «Навесы», «Парапеты», «Павильоны», «Мосты», «Вышки», «Выгребные ямы» и другие оставались без класса и превращались в «сети неизвестного типа» | layers_report генплана: 302 объекта unknown, 3 тыс. линий promoted | Добавлены в классификатор: здания и сооружения, опоры, канализация, игнорируемые |
| Подпорные стенки и парапеты без правила | Слой «Парапеты» (717 объектов) | Правило 3 м / 1 м «подошва подпорной стенки» из СП 42, не сверено |

| Посадки на проезжей части: 931 из 1152 на генплане Олимпийской деревни стояли на покрытии | Сравнение с эталоном проектировщика и картинки окон | Карта покрытий из подписей материалов топоплана, посадки только на грунте: 296 из 300 (`05`, `06` в заметках) |

| Блоки экспорта MicroStation (`msdElementType*`) читались как точки-символы | Заметка напарника по Берзарина; на образце красных линий 90 вставок `LineString` дали 44 точки, 14 текстовых блоков дали точки вместо подписей | Символ определяется по размеру блока (до 12 м) и не бывает блоком `msdElementType*`; такие блоки разбираются на геометрию, текстовые дают подписи |
| Подписи сетей `DIMTXT` со стрелкой-выноской стали бы трубами | Заметка напарника («красные ёлочки») | Из `DIMTXT` берётся только текст, линии выносок пропускаются |
| Чертёж Берзарина с привязанной подосновой не открывался: `ValueError` в ezdxf даже в режиме восстановления | `10004588_улица Берзарина_ГП.dwg` после dwg2dxf | LibreDWG 0.14 (и Windows-сборка, и Linux из нашего образа) режет длинные строки XML программы ESMT_LEP посреди `\U+XXXX` и оставляет сырые переводы строк. Загрузчик на запасном пути склеивает разорванные значения и заменяет битые `\U+`: 180 строк и 219 последовательностей, после чего 128 765 объектов, 26 922 линии сетей, 1 116 подписей диаметров |

| Проверка целостности на Берзарина: `ok: false`, 180 627 из 215 713 сущностей совпали | Первый полный прогон после ремонта строк | Сохранение исходника ezdxf без единой правки даёт те же 26 233 изменённых и 8 853 пропавших сущности, от писателя сервиса ноль. ezdxf на отремонтированном файле опускает атрибут ширины 0.0 у `LWPOLYLINE` и не сохраняет `REGION` без данных ACIS (LibreDWG их не конвертирует). Загрузчик после ремонта пропускает документ через запись ezdxf в памяти, снимок и результат строятся от него, число отброшенных сущностей по типам выводится в предупреждения |

| Прогон DWG в контейнере падал с `UnicodeDecodeError: 'utf-8' codec can't decode byte 0xf8` | `green run gp.dwg` в пересобранном образе на DWG Берзарина | `dwg2dxf` печатает в stderr имена слоёв в кодировке чертежа (cp1251), а конвертер читал вывод строгим UTF-8. Вывод LibreDWG и ODA теперь декодируется с заменой ошибок. Путь «DWG на вход сервиса» до этого проверялся только на DWG без кириллицы в выводе |

Берзарина после ремонта строк и нормализации (`10004588_улица Берзарина_ГП.dwg`, Linux-сборка LibreDWG, strict): 37 посадок, 796 отказов, целостность ok, 202 с (чтение с ремонтом 135 с). У проектировщика в эталоне 318 деревьев: разрыв пока не разобран.

Контрольные прогоны после правок: АСУ ОДХ (no_utilities) без изменений, 1 посадка и 259 отказов за 5.6 с; генплан Олимпийской деревни (strict) 1152 посадки вместо 1171, слоёв без класса ноль вместо 302 объектов, целостность ok, 163 с. Ни одной посадки в зоне ЛЭП не оказалось, правило 160-ПП на этом чертеже не сработало.
