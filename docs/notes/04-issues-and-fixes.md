# Проблемы, найденные по ходу, и что с ними сделано

| Проблема | Как проявилась | Исправление |
|---|---|---|
| `entity.dxf.get("name")` бросает исключение для сущностей без атрибута name | Прогон на АСУ ОДХ падал на проверке целостности (MPOLYGON) | Имя блока берётся только у INSERT |
| «Возд линии телеграф» классифицировались как подземный кабель связи | `green inspect` на топоплане | Отдельное правило для воздушных линий раньше кабелей |
| Слой «Подписи» АСУ ОДХ оставался без класса | `green inspect`, 364 объекта | Добавлен в игнорируемые |
| Ноль кандидатов на склеенном генплане | Бордюр из топоплана другого заказа лежал вне границы работ | Выгрузки склеиваются только в пределах одного заказа |
| Ноль кандидатов при правильном заказе | Бортовой камень нарисован штрихами по 0.7 м, ни один кусок не длиннее шага посадки | Станции строятся и по коротким фрагментам, шаг обеспечивает отбор по сетке, обход в Z-порядке |
| Отметок отказов больше, чем решений | На АСУ ОДХ 636 отказов на 8 км борта | Один отказ на шаг аллеи (сетка отказов), 259 вместо 636 |
| На АСУ ОДХ всего одна-две посадки | 98% кандидатов внутри тротуаров | Не ошибка: объект почти целиком замощён. Нужен режим посадки в приствольных решётках (в плане) |
| Медленное размещение (21 с) | 2.7 млн объектов проверок на 136 тыс. кандидатов | Вердикты векторно, объекты проверок только для выбранных решений (17 с) |
| Исходник загружался три раза | Чтение 37 с, запись 71 с, проверка 50 с на генплане | Кэш документа и снимок отпечатков в писателе: запись 43 с |
| Docker: `configure: error: pkg-config not found` | Сборка LibreDWG | pkg-config в сборочной стадии |
| Docker: `configure: error: no suitable Python interpreter found` | Сборка LibreDWG даже с `--disable-bindings` | python3 в сборочной стадии |
| Git Bash превращает `/dataset/...` в путь Windows | Команды `docker exec` | `MSYS_NO_PATHCONV=1` в скрипте проверки |
| Консоль Windows ломает кириллицу | Вывод Python в cp1251 | `PYTHONIOENCODING=utf-8`, результаты пишутся в файлы |
| Архив датасета пропал после распаковки | Скрипт по zip упал | Данные читаются из распакованной папки |
| Context7 недоступен | Исчерпана месячная квота | Версии по PyPI, GitHub, Hugging Face, Docker Hub; API по установленным пакетам |
| Критик workflow зациклился | Два ответа по 15 минут только с рассуждениями на усилии max | Критика разделена на части с усилием high |
