# Каталог под жёсткие квоты: какие виды добавлены и почему (16.09.2026)

После перехода на жёсткие квоты 10-20-30 план Берзарина занимал 200 мест из 301 (`notes/11-species-norms.md`). Здесь записано, как найдена причина, откуда взяты новые виды и как проверить каждый шаг.

## Шаг 1. Инструмент, который повторяет подбор без DXF

Полный прогон Берзарина идёт около 170 с, из них подбор видов - 2 с. Чтобы проверять правку каталога за секунды, подбор повторяется по готовому прогону:

```
uv run python tools/research/replay_assortment.py out/check/berzarina_norms --profile strict
```

Места и измеренные расстояния берутся из `plan.json`, существующие деревья - из `assortment.json`, нормы, каталог и профиль - текущие из `config/`. Вход - прогон, где все 301 место ещё в плане (`berzarina_norms`, до жёстких квот). Проверка инструмента: на каталоге до правок он дал 200 занятых мест, 101 в отказах и тот же состав, что полный прогон `berzarina_quota`.

## Шаг 2. Диагноз: в скольких местах семейство проходит нормы

Инструмент печатает, в скольких из 301 места хотя бы один вид семейства проходит все фильтры (369-ПП, 743-ПП п. 3.6.18, отступы с увеличением за крону, соль, зона):

| Семейство | Мест | Что отсекает (флаг `--why`) |
|---|---|---|
| Rosaceae, Sapindaceae | 301 | малые кроны проходят везде |
| Cupressaceae | 240 | туя |
| Pinaceae | 139 | крона 7-10 м: увеличение отступа до границы покрытия, борта и кабеля, у ели колючей и обыкновенной ещё 10 м до здания (`R-BLDCROWN-TREE-001`) |
| Salicaceae | 112 | тополь Симона |
| Malvaceae | 56 | крона липы 12-14 м: увеличение отступа до границы покрытия (55-64 мест), здания, борта |
| Oleaceae, Ulmaceae, Fagaceae | 40, 34, 10 | кроны 14-18 м: те же увеличения отступов |

```
uv run python tools/research/replay_assortment.py out/check/berzarina_norms --why Pinaceae Malvaceae Oleaceae Ulmaceae Fagaceae
```

Таблица снята на каталоге до правок; после того как сосна горная стала деревом, Pinaceae допустимо во всех 301 месте.

Sapindaceae закрыто существующими деревьями (389 из 718 на улице, заметка прогона). Допуски оставшихся пяти семейств в сумме дают ровно 100% (30 + 30 + 20 + 10 + 10), поэтому больше 200 мест не занять. Вывод: нужны малые деревья, устойчивые к соли, из семейств, которых в плане нет.

## Шаг 3. Кандидаты из данных заказчика

В перечётных ведомостях пилота есть лист «Справочник пород» - справочник ДПиООС для расчёта компенсационной стоимости: 649 пород, жизненная форма (дерево или кустарник), код ценности. Выгрузка и сверка с каталогом:

```
uv run python tools/research/city_species_dictionary.py [--dump dictionary.csv]
```

Что из этого следует:

- Коды ценности: 1 - хвойные, 2 - ценные лиственные, 3 - плодовые и мелкие, 4 - малоценные (примечание справочника: «учитывается при расчете итогов по малоценным породам»). У айланта, дуба красного, клёна ясенелистного, ореха маньчжурского, робинии, черёмухи виргинской и ясеня пенсильванского кода нет - это семь из девяти деревьев перечня 369-ПП. Проверку запускает тест `tests/test_city_dictionary.py`.
- Две ошибки каталога: ирга колосистая стояла деревом (у заказчика кустарник), сосна горная - кустарником (у заказчика дерево, код 1). Исправлено, тот же тест теперь сверяет жизненную форму каждого вида.
- Карагана и сирень амурская у заказчика - кустарники, в план деревьев не годятся.
- Деревья из новых семейств с кодом 2: лох узколистный (Elaeagnaceae), маакия амурская (Fabaceae), вяз приземистый или мелколистный (Ulmaceae, другой вид, род *Ulmus* на улице занят на 13%).

Были ли эти виды в проектах пилота, проверено поиском по всем таблицам датасета:

```
uv run python tools/research/species_mentions.py "лох " "маакия" "вяз мелколист" "вяз приземист"
```

Совпадения только на листах «Справочник пород» и «Списки», то есть в выпадающих списках шаблона, а не в ведомостях посадок. Поэтому `pilot_streets: 0`.

## Шаг 4. Свойства видов со ссылкой на страницу

Первый проход собрал данные поиском, но часть цитат была из поисковых сниппетов: сайт Missouri Botanical Garden не открылся. Такие значения не приняты. Второй проход загрузил страницы и вернул дословные строки. В каталог попали только они, у каждого значения источник в `sources`.

| Вид | Источник | Дословно | Что в каталоге |
|---|---|---|---|
| Маакия амурская | woodyplants.cals.cornell.edu/plant/142 | «Hardy To Zone: 4a»; «Height: 20' - 30' (equal or wider spread)»; «Salt Tolerance: Tolerates salty soil»; «white pea-like flowers in June/July»; «Insect Disease: none serious» | зона 4, высота 9 м, крона 8 м, соль 2, декоративность 6-7, уход 1 |
| Лох узколистный | plants.ces.ncsu.edu/plants/elaeagnus-angustifolia/ | «USDA Plant Hardiness Zone: 2a ... 7b»; «Height: 12 ft. 0 in. - 30 ft. 0 in.»; «Width: 12 ft. 0 in. - 20 ft. 0 in.»; теги «#salt tolerant», «#drought tolerant» | зона 2, высота 7 м, крона 5 м, соль 2 |
| Вяз приземистый | plants.ces.ncsu.edu/plants/ulmus-pumila/ | «USDA Plant Hardiness Zone: 4a ... 9b»; «Height: 50 ft. 0 in. - 70 ft. 0 in.»; «Width: 35 ft. 0 in. - 50 ft. 0 in.»; «Problems: Frequent Insect Problems / Messy / Weak Wood / Weedy»; «copious seed formation» | зона 4, высота 18 м, крона 12 м, `fruit_litter: true` |

Не найдено ни в одном загруженном источнике и оставлено по умолчанию с пометкой «не найдено»: аллергенность всех трёх, срок жизни, газоустойчивость маакии и лоха, солеустойчивость вяза. Лох на странице назван инвазивным в Северной Каролине; в перечне 369-ПП его нет, это записано в `sources`.

Вяз приземистый внесён, но запрещается: массовый самосев и пометка «Messy» - основание 743-ПП п. 3.6.18 («засоряющих территорию во время плодоношения»). Он в каталоге, чтобы отказ срабатывал явно и с причиной, как у клёна ясенелистного.

## Шаг 5. Проверка

Повтор подбора (шаг 1) после каждой правки:

| Каталог | Занято из 301 | В отказах | Нарушения квот | Видов | Шеннон |
|---|---|---|---|---|---|
| до правок | 200 | 101 | 0 | 13 | 2,45 |
| ирга - кустарник, сосна горная - дерево | 221 | 80 | 0 | 12 | 2,37 |
| плюс маакия, лох, вяз приземистый | 280 | 21 | 0 | 13 | 2,46 |

Аллея у борта заполнена целиком (52 из 52), на газонах 228 из 249. Состав: боярышник, лох узколистный, ель колючая, сосна горная, туя по 28, ель обыкновенная и яблоня декоративная по 27, тополь Симона 26, маакия 20, черёмуха виргинская 15, рябина 14, липа мелколистная 10, сосна обыкновенная 1. Доли на границе квот, но не выше: вид 10%, Pinaceae и Rosaceae по 30%, хвойные 40%.

По ходу нашлась ошибка решателя. Сосна горная, ставшая деревом, допустима почти везде, и задача с двоичной переменной «один экземпляр» на каждый ключ не решалась за 60 с. Жадный запасной путь при этом срезал план до 4 мест. Исправлено двумя правками в `assign.py`: исключение «один экземпляр» оставлено только для участков, где доля меньше одного растения; решателю задан допустимый зазор 0,5% до оптимума. Если время всё же кончилось, берётся найденное решение, когда квоты на нём выдержаны.

Полный прогон DXF (`gp.dxf`, профиль `strict`, перечётка Берзарина, результат в `out/check/berzarina_catalog`) совпал с повтором подбора один в один: 280 посадок, 21 место в отказах, `quota_violations` пусто, Шеннон 2,46, хвойных 40%. Целостность `ok`, 206 860 исходных сущностей без изменений. Время 175 с, из них подбор 1,5 с. Условия допуска в плане: тополь Симона 26 посадок (только мужские клоны), черёмуха виргинская 15 (369-ПП, группа III, меры против распространения).

```
uv run green run gp.dxf --profile strict --inventory "dataset/Датасет/Пилотный проект 20 улиц/16. улица Берзарина/Исходные данные/Перечетка_улица Берзарина.xls" --out out/check/berzarina_catalog
```

## Что осталось

- 21 место на газонах пустое. Следующие кандидаты - деревья с кодом 2-3 из справочника заказчика в семействах, которых в плане нет: граб обыкновенный (Betulaceae), хмелеграб японский (Betulaceae), кладрастис жёлтый (Fabaceae). Для каждого нужны зона, крона и соль из загружаемого источника.
- Аллергенность маакии и лоха не подтверждена источником. Если окажется массовой, п. 3.6.18 их запретит.
- Жадный запасной путь при жёстких квотах слабый: если решатель не найдёт ни одного решения, план сильно сократится. С зазором 0,5% на Берзарина этого не происходит, но на большом генплане не проверено.
- Срок жизни у новых видов 0 («не найдено»), фактор долговечности в оценке для них нулевой. Оценка от этого занижена, нормы не затронуты.
