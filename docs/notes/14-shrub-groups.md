# Группы кустарников на местах, пустых из-за квот деревьев (16.09.2026)

Решение из `notes/13-empty-places-allergens-fallback.md`: облепиху в каталог не вносить (инвазивный вид группы III и неподтверждённая крона), а места, которые квоты деревьев оставили пустыми, отдать под группы кустарников. ТЗ требует план деревьев и кустарников, так что это функция плана, а не подгонка цифры.

## Шаг 1. Как устроено

- `src/green/application/shrub_groups.py`, `fill_shrub_groups`: после подбора деревьев берутся отказы с причиной-квотой (`Rejection.note`), это места, допустимые по нормам для дерева. Каждое место - центр группы.
- `GreedyPlantingStrategy.shrub_groups`: квадрат `shrub_group_size` × `shrub_group_size` (3 × 3) с шагом `shrub_group_spacing_m` (1 м) вокруг центра. Каждая точка проверяется как посадка: грунт по карте покрытий, граница работ, все правила расстояний для кустарника. Правила по роду не применяются, пока вид не выбран: их проверяет подбор.
- Виды назначает тот же подбор ассортимента с жёсткими квотами, среди кустарников и отдельно от деревьев. Существующие растения из перечётки теперь делятся по жизненной форме: квоты деревьев считаются по существующим деревьям, квоты кустарников - по кустарникам.
- Если в группе посажен хотя бы один кустарник, отказ дерева на этом месте снимается.
- Результат: слои `GREEN_SHRUBS` и `GREEN_SHRUBS_APPROVAL`, блоки `GREEN_SHRUB_<ВИД>`, сводка `assortment_shrubs.json`, строка «Группы кустарников: ...» в предупреждениях.
- Включается параметром профиля `shrub_groups` (по умолчанию да), только для прогона деревьев в режиме `auto`.

Шаг группы 1 м - толкование. 743-ПП, табл. 3.6.2 («Ориентировочные расстояния между деревьями и кустарниками»): групповая посадка кустарников 0,3 м, однорядная посадка высоких кустарников 0,5-1 м. У кустарников каталога крона через 10 лет 0,8-2,5 м, при шаге 0,3 м они сомкнутся сразу. Принято верхнее табличное значение для высоких кустарников.

## Шаг 2. Тесты

`tests/test_shrub_groups.py` на синтетической улице (`test_pipeline_synthetic._street`):

- место с отказом по квоте становится группой из 1-9 кустарников в пределах 1 м от центра, отказ дерева снимается, квоты кустарников не нарушены;
- точки ближе 1,5 м к стене здания (R-BLD-SHRUB-001, СП 42 табл. 9.1) в группу не входят;
- отказ по нормам (без `note`) кустарником не заполняется;
- параметр `shrub_groups: false` выключает проход.

## Шаг 3. Прогон Берзарина: ни одной группы

```
uv run green run gp.dxf --profile strict --inventory "dataset/Датасет/Пилотный проект 20 улиц/16. улица Берзарина/Исходные данные/Перечетка_улица Берзарина.xls" --out out/check/berzarina_shrubs
```

- Деревья без изменений: 280 посадок, 21 место в отказах, квоты выдержаны. Состав деревьев немного сдвинулся (маакия 23 вместо 20), потому что из существующей популяции деревьев убраны 78 кустарников перечётки.
- Кустарники: из 21 места 177 точек групп прошли нормы, посажено 0.
- Стадия `shrub_groups` 8,7 с (в основном повторная карта покрытий), целостность `ok`, 206 860 исходных сущностей без изменений.

Предупреждения прогона называют причину:

- Существующих кустарников по перечётке 78. Rosaceae (29 из 78), Oleaceae (29), вид *Syringa josikaea* (29), *Lonicera tatarica*, *Physocarpus opulifolius*, *Spiraea vanhouttei* уже выше своей доли, новых посадок с ними нет.
- После норм и закрытых семейств остаются 8 видов кустарников в 4 семействах: *Cornus alba*, *C. sericea* (Cornaceae), *Hydrangea paniculata*, *H. arborescens*, *Philadelphus coronarius* (Hydrangeaceae), *Euonymus europaeus* (Celastraceae), *Juniperus sabina*, *J. communis* (Cupressaceae). При доле 10% на вид восемь видов дают не больше 80% плана, поэтому ни одно T > 0 квоты 10-20-30 не выдерживает.

## Вывод и что дальше

Правило 10-20-30 (Santamour, 1990) сформулировано для популяции городских деревьев. Для кустарников его в источнике нет, а применённое как есть к группам кустарников оно на Берзарина не даёт посадить ничего. Кроме того, счёт кустарников в перечётках пилота ненадёжен: единицы в ведомостях не унифицированы (`docs/species.md`, «Эмпирика пилота»), у части строк количество не указано и принято одно растение.

Варианты, нужно решение:

1. Для кустарников отдельные доли в профиле (например, из профиля `shrubs`: вид 20%, род 35%, семейство 50%). Это параметр проекта без внешнего источника, и так его и назвать. Квоты остаются жёсткими, меняются только числа.
2. Для кустарников не учитывать существующую популяцию из перечётки, пока единицы в ведомостях не сверены.
3. Оставить как есть: места остаются в отказах с причиной.
