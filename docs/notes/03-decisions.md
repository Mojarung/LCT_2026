# Принятые решения

| Решение | Почему | Альтернатива и почему не она |
|---|---|---|
| Гексагональная архитектура в одном пакете `green`, контракты import-linter | Чистые границы без накладных расходов монорепо; нарушение слоёв ломает проверку | uv workspace из девяти пакетов: лишняя сложность на этапе хакатона |
| Домен на frozen dataclass, pydantic только на границе (конфиги, API) | Ядро без фреймворков, быстрые неизменяемые объекты | pydantic в домене: связывает ядро с библиотекой валидации |
| Нормы как данные: `rule_id` отдельно от цитаты, статусы verified / unverified / not_found | Смена редакции не ломает код, неподтверждённая ссылка видна в объяснении | Нормы в коде: нельзя обновить без релиза |
| Акт `PROJECT` для параметров команды | Честно отделяет проектные решения (4 м до существующего дерева, колодец как признак сети) от норм | Выдавать параметры за нормы: эксперт найдёт подмену |
| Fail-closed и профили `strict` / `no_utilities` | Нет данных о сетях: нет посадки или посадка с согласованием, решение явное | Молча сажать без сетей: риск для инженерных сетей |
| Векторные проверки: STRtree.query_nearest + numpy, объекты проверок строятся лениво | 136 тыс. кандидатов на генплане считаются за секунды | Проверка по одной точке: минуты |
| Жадная аллея вдоль борта со станциями и по штрихам | Работает на сплошном борте АСУ ОДХ и на штриховом борте Геотреста, детерминирована | Сразу CP-SAT: сначала нужен рабочий срез; CP-SAT встанет за тем же портом |
| Объяснения только по шаблонам из трассы правил | Ни одного выдуманного пункта | LLM в рантайме: риск галлюцинаций, закрытый контур |
| Слои результата `GREEN_*`, блоки на вид, атрибуты NUM / SPECIES / NPA, XDATA `LCT_GREEN` | Требование ТЗ об отдельном слое, трассировка прямо в CAD | Отдельный DXF только с результатом: теряется контекст подосновы |
| Проверка целостности по отпечаткам DXF-тегов (blake2b), снимок исходника до записи | Доказательство, что исходные сущности не изменены, одной загрузкой меньше | Сравнение числа сущностей: не ловит изменение атрибутов |
| Кэш документа между читателем и писателем | Минус одна полная загрузка большого DXF (минус 28 с на генплане) | Передавать ezdxf-документ через порты: протечка библиотеки в ядро |
| LibreDWG по умолчанию в образе, ODA File Converter опционально при сборке | GPL не смешивается с кодом (отдельный процесс), бинарник ODA не распространяется нами | ODA в образе всегда: вопрос лицензии для поставки |
| Ubuntu 26.04 LTS, Python 3.14 от uv, venv копируется в runtime-образ | Текущий LTS, близость к МосТех.ОС, быстрый Python от python-build-standalone | python:3.14-slim (Debian): дальше от Ubuntu-подобной целевой ОС |
| Granian вместо uvicorn | Сервер на Rust, быстрее, есть programmatic API | uvicorn: медленнее |
| cyclopts для CLI | Лёгкий, типизированный | Typer: тоже подходит, выбор по скорости старта |
| orjson только для артефактов | В FastAPI 0.141 `ORJSONResponse` помечен deprecated, ответы сериализует pydantic | orjson в API: устаревший путь |
| uuid7 для прогонов, файловое хранилище со статусом | Время в id, сортировка, без БД на этапе хакатона | PostgreSQL: пока не нужен, порт `RunStore` позволяет заменить |
| RFC 9457, CORS из настроек, версия `/api/v1` | Фронтенд подключается без переделок | Произвольные ошибки: клиенту сложнее |
| ty как тайпчекер | Самый быстрый, от авторов ruff и uv | Он в бете (0.0.81); при ложных срабатываниях можно добавить mypy 2.3 |
