# База видов `config/species.yaml`

Каталог ассортимента: из него подбирается вид для каждой посадки (см. `docs/algorithm.md`,
раздел «Подбор ассортимента»). Сейчас 52 записи: 27 деревьев (17 первой величины, 3 второй,
7 третьей) и 25 кустарников, 34 рода, 15 семейств, 8 хвойных.

Почему YAML, а не база: записей меньше сотни, правка видна в git-диффе, эксперт ДПиООС
проверяет файл глазами, а схема валидируется так же строго, как `rules.yaml`
(`SpeciesModel` в `src/green/infrastructure/config/schemas.py`).

## Как устроена запись

```yaml
  - {code: tilia_cordata, name_ru: Липа мелколистная, name_lat: Tilia cordata, genus: tilia,
     family: Malvaceae, life_form: tree_large, height_m: 25, crown_diameter_m: 4.0,
     crown_mature_m: 12, ...
     status: reference,
     sources: {hardiness_zone: "USDA, каталоги питомников", salt_tolerance: "Колесников 1974"}}
```

### Таксономия

| Поле | Смысл |
|---|---|
| `code` | устойчивый идентификатор, попадает в имя блока DXF (`GREEN_TREE_TILIA_CORDATA`) |
| `name_ru` | имя в объяснениях, подписях и ведомостях |
| `name_lat` | латинское имя; первое слово обязано совпадать с `genus` (проверяется при загрузке) |
| `genus` | род в нижнем регистре: по нему работают правила отступов по роду (МГСН 1.02-02 п. 4.2.8) и квота рода |
| `family` | семейство **по APG IV**: липа — Malvaceae, клён и каштан — Sapindaceae. Традиционные Tiliaceae и Aceraceae не используются: семейство нужно для квоты разнообразия, где важна общая уязвимость к вредителю, а не привычка справочника |

### Габарит

| Поле | Смысл |
|---|---|
| `life_form` | `tree_large` (≥20 м), `tree_medium` (10–20), `tree_small` (<10), `shrub_tall` (>2), `shrub_medium` (1–2), `shrub_low` (<1), `groundcover`, `perennial`. Определяет, к какому типу посадки вид вообще допускается |
| `height_m` | взрослая высота. По ней работает ограничение под воздушными линиями (`max_height_under_lines_m`) |
| `crown_mature_m` | взрослый диаметр кроны. Больше 5 м — увеличенные отступы по прим. к табл. 9.1 СП 42.13330.2016 |
| `crown_diameter_m` | крона через 10 лет, только для отрисовки условного знака |
| `root_type` | `surface` / `tap` / `mixed` — пока справочное поле для будущего правила о корнях у сетей |
| `growth`, `lifespan_years` | скорость роста и долговечность; долговечность входит в оценку |

Посадочная высота саженца из паспортов («500–600 см») в `height_m` **не попадает**: это размер
при поставке, а не взрослая высота. Инструмент `tools/build_species_catalog.py` печатает её
отдельной строкой комментария.

### Экология и шкалы 0–2

`salt_tolerance`, `gas_tolerance`, `compaction_tolerance` — 0 не переносит, 1 средне, 2 устойчив.

- `salt_tolerance: 0` — хвоя или листья горят от реагентов, вид не ставится в полосе
  `salt_zone_m` (5 м по умолчанию) от проезжей части и борта: ель, сосна, берёза, каштан,
  гортензия, туя.
- `salt_tolerance: 2` — вид применяют в разделительных полосах: вяз, дёрен, кизильник,
  пузыреплодник, клён Гиннала, тополь, ирга.
- `hardiness_zone` — минимальная зона USDA, которую вид переносит. Москва — 4 (4b–5a), поэтому
  вид с зоной 5 по умолчанию отсеивается с причиной-справочником. Таких три: скумпия, форзиция,
  вейгела — все три встречаются в паспортах пилота, то есть проектировщики их сажают, принимая
  подмерзание. Чтобы разрешить, нужен профиль с `region_hardiness_zone: 5`.
- `light` — минимальная потребность в свете, `moisture` — отношение к влаге. Пока не участвуют
  в фильтрах: тень от зданий не считается (нужна этажность, см. «Смежные задачи» в плане).

### Ограничения

| Поле | Как применяется |
|---|---|
| `invasive_group` | группа по 369-ПП. Обязана совпадать с запретом в `config/rules.yaml`: тест `test_invasive_species_carry_group_and_are_banned` падает при расхождении |
| `fluff` | пух. Норма 743-ПП п. 3.6.18 — такие виды не ставятся ближе `housing_zone_m` (30 м) к зданиям |
| `allergen` | 0–2. **Не фильтр, а штраф в оценке:** запрет аллергенов нормой не установлен, выдавать рекомендацию за норму нельзя |
| `toxic`, `thorny` | пока справочные: правило появится вместе с классом «детская площадка» |
| `fruit_litter` | плоды, засоряющие покрытие |

### Декоративность и применение

`decor_months` — месяцы **пика** декоративности (цветение, осенняя окраска, зимняя кора или
хвоя), а не весь вегетационный период. В паспортах пилота пик записан широко («с мая по
октябрь»), поэтому значения выставлены вручную по описаниям, а не импортом.

`uses` — `row` (рядовая посадка), `group`, `solitaire`, `hedge`, `under_lines` (низкорослые,
допустимые в охранной зоне ВЛ), `grate` (в приствольной решётке). Влияет на фактор `function`
в оценке.

`care_level` — 1 минимальный уход, 3 требовательный (полив, обработка от вредителя, укрытие).

### Эмпирика пилота

`pilot_streets` — в скольких паспортах из семи встречается род (сорта и торговые названия
склеены). `pilot_count` — суммарное количество по ведомостям; **единицы в паспортах не
унифицированы** (для деревьев штуки, для почвопокровных встречаются величины порядка десятков
тысяч), поэтому величина справочная и в оценке не участвует. Оба поля считает
`tools/build_species_catalog.py` из `dataset/catalog/species_from_passports.csv`.

## Источники и статусы

`status` записи: `verified` — значение сверено с актом, `reference` — справочник,
`pilot` — из паспортов пилота, `draft` — требует проверки. `sources` — словарь «имя поля →
откуда значение»; обязательны ключи `hardiness_zone` и `salt_tolerance` (проверяется при
загрузке). Справочник по умолчанию — Колесников А.И. «Декоративная дендрология»
(М.: Лесная промышленность, 1974); зоны и габариты сверены с каталогами питомников.

Это разделение — не формальность: объяснение посадки обязано различать норму (акт и пункт),
рекомендацию справочника и эмпирику пилота. Норма звучит как «запрещено по 369-ПП», справочник —
как «по справочнику не переносит реагенты».

## Известные пробелы

- Полного текста приложения 369-ПП нет: группы инвазивности проставлены по ресерчу.
  Запрет рябинника рябинолистного (`R-INV-SORBAR-001`) расходится с практикой — вид стоит
  в паспортах двух улиц пилота, 4725 шт. До демонстрации сверить текст приложения.
- Приложение 515-ПП (базовый ассортимент для города) не найдено; когда появится, оно даёт
  проверенный список и заменит часть `reference` на `verified`.
- Каталоги типовых посадок, обещанные ТЗ, не выданы. Когда появятся — импорт в этот же формат
  отдельным конвертером, режим `assortment_mode: given` уже умеет работать по заданному списку.

## Как добавить вид

1. Дописать запись в `config/species.yaml` (обязательные поля перечислены в `SpeciesModel`).
2. Если вид инвазивный — добавить запрет в `config/rules.yaml` с `rule_id` и цитатой, иначе
   тест согласованности упадёт.
3. Прогнать `uv run pytest tests/test_species_catalog.py -q`.

## Как импортировать чужой каталог

`tools/build_species_catalog.py` — образец: читает выгрузку, склеивает сорта и торговые
названия (контейнеры «с3», «С7,5-С10», крупномер, латынь в скобках), считает частоту по
улицам и печатает YAML-черновик с `status: draft` и `TODO` в полях, которые нельзя вывести
из источника (латинское имя, семейство, экология). Черновик в каталог автоматически не
попадает: латинских имён в паспортах нет, а экологию проставляет человек.
