## С чем согласен

- Конвейер без LLM в рантайме, нормы как данные, стабильный rule_id отдельно от цитаты.
- Конвертеры только отдельным процессом: GPL LibreDWG не смешивается с кодом, ODA ставится при сборке у заказчика.
- Fail-closed: нет данных о сетях, значит нет посадки или посадка с согласованием.
- Существующие деревья из перечётной ведомости как препятствия, без автоматической вырубки.
- Эксперименты: стресс-тест охранных зон, «хаос XREF», слепая экспертная оценка, сравнение жадной расстановки с CP-SAT, leave-one-street-out.

## С чем не согласен

- Локальная LLM для построения `layer_map.yaml` в обязательном контуре. На данных пилота слои названы по-русски и однозначно: регулярные выражения покрыли все слои топоплана и сетей. LLM можно оставить как подсказку для незнакомого DXF.
- Схема «последовательная выгрузка LLM и модели визуализации из 8 ГБ VRAM» для ядра не нужна. Визуализация остаётся бонусом после DXF.
- Утверждение «размещение посадок улицы занимает секунды». На генплане Олимпийской деревни (309 тысяч сущностей) чтение и запись DXF в ezdxf занимают больше двух минут, само размещение 17 с.

## Что показали данные (помимо ресерча)

- Бортовой камень в топоплане Геотреста нарисован штрихами по 0,7 м (22 759 отрезков), а не сплошной линией. Алгоритм строит станции и по штрихам.
- Диаметры сетей подписаны текстом `d=400ж.б.`, `d=150ац.`, `d=200чуг.`, число прокладок `2тр.`, `4к.`.
- Выгрузки одного заказа нужно склеивать вместе: топоплан другого заказа лежит вне границы работ.
- Фото «до»: GPS есть только у трёх улиц, направления съёмки нет ни в одном кадре, большая часть кадров пересжата до 1280x960 без EXIF.
