## 1. Назначение и границы решения {#scope}

### 1.1. Задача

Сервис `green` по чертежу участка улицы в DXF (геоподоснова АО «Мосгеотрест», сети,
генплан) проектирует посадки деревьев и кустарников и газоны с соблюдением нормативных
отступов и возвращает результат в DXF. Результат лежит только на отдельных слоях `GREEN_*`.
Исходные слои не изменяются, и это проверяется после каждой записи. Каждая посадка и каждое
отклонённое место сопровождаются объяснением со ссылкой на акт, пункт и таблицу. Объяснение
собирается из трассы проверенных правил без генеративной модели.

Решение алгоритмическое: геометрия (Shapely/GEOS), целочисленная оптимизация (HiGHS через
SciPy), нормы как данные (`config/rules.yaml`). Нейросети в расчёте не участвуют. Это
соответствует п. 3 раздела 2 ТЗ: «главное - корректный, воспроизводимый и объяснимый
результат».

### 1.2. Вход и выход

| | Что | Формат |
|---|---|---|
| Вход | чертёж участка: геоподоснова, сети, генплан, дендроплан; один файл или комплект с внешними ссылками | DXF (ASCII и binary), DWG через конвертер |
| Вход (по наличию) | слои ГИС: охранные зоны, здания и границы data.mos.ru, кадастр, зонирование | GeoJSON, SHP в .zip |
| Вход (по наличию) | перечётная ведомость существующих деревьев | XLS, XLSX |
| Параметры | профиль норм и переопределения: шаг, приёмы, редакция СП 42, отключаемые правила | YAML-профиль, JSON, `--set` |
| Выход | копия исходного чертежа со слоями результата `GREEN_*` | DXF (версия исходника) |
| Выход | интерпретации: строка на пару «решение - правило» | JSON, CSV |
| Выход | читаемый отчёт интерпретаций: определяющая норма каждой посадки | Markdown, HTML для печати в PDF |
| Выход | ведомость посадочного материала, сводки плана, проверки | CSV, JSON |
| Выход (бонус) | 3D-сцена участка и снимки | JSON сцены, PNG |

### 1.3. Что входит в решение

| Требование ТЗ (раздел 2, «Что должен уметь сервис», п. 1-9) | Реализация |
|---|---|
| 1. Приём пространственных данных | DXF и DWG; сборка комплекта по внешним ссылкам; склейка нескольких файлов; слои ГИС (GeoJSON, SHP) с пересчётом WGS 84 в МСК-Москва (разд. 3.13) |
| 2. Ограничения и карта «где можно сажать» | 62 правила расстояний до 27 классов объектов; охранные зоны ВЛ и газопровода; карта покрытий «грунт/твёрдое»; зоны допустимости (разд. 3.5, 3.6, 3.13) |
| 3. Рекомендация локаций | деревья: аллея вдоль борта, сетка по газону, добор; кустарники: ряд у борта, живая изгородь, подлесок, группы на газоне; травянистые покрытия: газоны на свободном грунте (разд. 3.7, 3.9) |
| 4. Генерация плана с отступами | портфель вариантов, отбор мест жадно и MILP, подбор вида MILP, независимая проверка (разд. 3.7-3.10) |
| 5. Результат на отдельных слоях | 11 слоёв `GREEN_*`, исходные сущности сверяются по отпечаткам blake2b (разд. 3.12) |
| 6. Корректировка результата | параметры профиля и JSON; правка на карте: перенос, удаление, проверка точки; пересборка DXF (разд. 3.15, 6) |
| 7. Экспорт в DXF | копия исходника в его версии и единицах; проверка соответствия записанного плана (разд. 3.12) |
| 8. Интерпретируемость | объяснение каждой посадки и отказа: правило, измерение, норма, акт, пункт, дословная цитата (разд. 3.14) |
| 9. Бонус: визуализации | 3D-вид из плана: здания с этажностью, покрытия, посадки по видам и возрасту; снимки PNG (разд. 3.15); фото по кадру 3D-вида моделью Qwen-Image-2.1 на видеокарте, вне Docker-образа (разд. 5.9) |

### 1.4. Границы MVP и что оставлено на развитие

Сделано и проверено:

- Полный конвейер DXF → план → DXF на улицах пилота: {{streets_summary}} (приложение B), с
  нулём нарушений норм в выданных планах по независимой проверке.
- Чтение без потерь: учёт каждого примитива исходника. Нечитаемая геометрия останавливает
  расчёт, а не пропускается молча. Сверка «чернил»: исходник отрисовывается движком ezdxf,
  каждая линия ищется в сцене.
- Нормы как данные: {{rules_total}} правил. У {{rules_by_text}} основание сверено по
  тексту акта; {{rules_project}} - проектные параметры, где акт требует величину, но не
  задаёт её, или норма взята по аналогии; {{rules_definitions}} - проектные определения
  газонов.
- Интерпретации в машиночитаемом (JSON, CSV) и читаемом (Markdown, HTML) виде.
- Веб-интерфейс, HTTP API с OpenAPI, CLI, Docker.

На развитие:

| Направление | Что нужно | Почему не в MVP |
|---|---|---|
| Кадастр и зонирование как ограничения | правила по видам разрешённого использования и зонам | данные пилота их не содержат; сейчас слои принимаются к сведению (разд. 3.13) |
| Типовые элементы сквера | генерация площадок, дорожек, МАФ | ТЗ называет их среди типов посадок, но для улиц пилота не было данных о функциональных зонах сквера |
| Охранные зоны по линиям сетей | зоны газопровода, связи, теплосетей от линий чертежа | правило есть (ПП РФ № 878), отключено по ответу заказчика (разд. 8) |
| Автоматическая проверка в nanoCAD | сценарий открытия и снимков | проверено в LibreCAD под Linux в контейнере (разд. 5.6) |
| Корнеобитаемый объём и почвы | данные изысканий | в чертеже их нет; посадочное место - габарит ямы по 743-ПП |

### 1.5. Термины

| Термин | Значение в документе |
|---|---|
| Посадочное место | габарит ямы в плане: дерево - круг радиусом 1,24 м (равновеликий яме 2,2 × 2,2 м под ком 1,3 × 1,3 м, 743-ПП, табл. 3.3.1), кустарник - круг радиусом 0,5 м |
| Отказ | место-кандидат, отклонённое нормой или составом плана, с причинами; в DXF - отметка на `GREEN_REJECT` |
| Вердикт | «допускается», «требует согласования», «запрещено»; для отсутствующих данных - «нет данных» |
| Правило | запись `config/rules.yaml`: класс объекта, тип посадки, норма, способ измерения, последствие, основание |
| Профиль | набор параметров прогона `config/profiles/*.yaml`: `strict` (строгий), `barriers` (прикорневые барьеры), `no_utilities` (чертёж без сетей), `shrubs` (только кустарники) |
| Эталон | план проектировщика из папки «Проектное решение» пилота. Эталон задаёт формат и состав выхода, а не оптимум: {{audit_short}} (разд. 3.16) |
| Трасса правил | все проверки правил для посадки или отказа: `rule_id`, измеренное расстояние, норма, исход, ближайший объект чертежа |
| Определяющая норма | проверка посадки с наименьшим запасом «измерено минус норма» |
| Пробел чтения | примитив чертежа, пространственную геометрию которого сервис не смог прочитать; останавливает расчёт |
| Сверка «чернил» | отрисовка исходника движком ezdxf и поиск каждой нарисованной линии в прочитанной сцене |
| Грунт по подписи | грунт вне замкнутых граней, выведенный по ближайшей подписи материала (до 30 м) |
| Станция | точка на оси борта через шаг посадки, на которой аллея выбирает одно место дерева |
| Портфель вариантов | несколько полных планов одной улицы разными приёмами отбора; выдаётся прошедший проверку с лучшим индексом |
| Индекс качества | взвешенная сумма десяти мер плана к целям участка, от 0 до 1 (разд. 3.11); версия формулы - v3 |
| Подлесок | малая группа кустарника под кроной дерева без нижнего яруса |
