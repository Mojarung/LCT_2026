## 6. Способы взаимодействия {#interaction}

Все три способа вызывают один сценарий `PlanSite` с одними нормами. Разница только в форме
входа и выхода.

### 6.1. Командная строка

| Команда | Назначение |
|---|---|
| `green run ВХОД [ЕЩЁ…] [--profile P] [--set k=v] [--layer ГИС] [--inventory ВЕДОМОСТЬ] [--out ПАПКА]` | прогон: DXF или DWG, комплект, слои ГИС, переопределения параметров; печатает сводку и пути артефактов в JSON |
| `green audit ПЛАН --plantings ШАБЛОН [--trees …] [--shrubs …]` | нормоконтроль посадок проектировщика теми же правилами |
| `green inspect ФАЙЛ` | чтение без расчёта: классы, слои, единицы, пробелы чтения |
| `green verify ИСХОДНИК РЕЗУЛЬТАТ` | сверка исходных сущностей по отпечаткам |
| `green serve [--host] [--port] [--workers]` | HTTP API и веб-интерфейс |
| `green openapi --out ФАЙЛ` | выгрузка схемы OpenAPI |

Параметры задаются профилем (`--profile strict|barriers|no_utilities|review|shrubs`) и
переопределениями `--set`. Например, `--set spacing_m=6`, `--set crown_spacing=false`
(один шаг на все породы вместо шага по взрослым кронам), `--set sp42_edition=2026`,
`--set 'disabled_rules=[]'` (включает охранную зону газопровода по линии сети). Все параметры -
приложение D.

### 6.2. Веб-интерфейс

React-приложение (`frontend/`) ходит только в `/api/v1`.

- **Консоль.** Выбор улицы пилота или своего чертежа, комплекта, перечётной ведомости, слоёв
  ГИС. Параметры: профиль, шаг, приёмы размещения, прикорневые барьеры, JSON поверх профиля.
  Реестр прогонов с этапом и оценкой остатка времени.
- **Рабочее место прогона.** Карта плана в стиле бумажного чертежа:
    - подоснова, сети по видам, газон и покрытия, как их понял сервис;
    - посадки кронами по видам, отказы, места с барьером, слабые места, газоны, зоны
      допустимости;
    - справа: индекс качества с разбором по слагаемым и состав плана по видам.
- **Карточка посадки или отказа.**
    - ближайшие нормы с выносками расстояний на карте;
    - правило, пункт акта, таблица, цитата;
    - почему этот вид, альтернативы, вклад в индекс.
- **Правка.** Перенос мышью или Alt со стрелками с живой проверкой точки, удаление, новое место
  по клику, пересборка DXF. Отказ сервиса возвращает посадку на место.
- **Выгрузка.** DXF, интерпретации CSV, отчёт интерпретаций (HTML для печати в PDF), все
  файлы прогона.
- **3D-вид** (`/runs/<id>/3d`). Полёт и пешеход, облёт по оси улицы, сезон, возраст посадок,
  время суток, погода, снимок PNG.
- **База моделей растений** (`/models`): как каждый из 55 видов нарисован на плане.

Тема светлая «бумага» и тёмная, переключатель вверху справа.

### 6.3. HTTP API

`/api/v1`, JSON, ошибки в формате RFC 9457 (`application/problem+json`). Методы - разд. 7.
