## 6. Способы взаимодействия {#interaction}

Командная строка, веб-интерфейс и HTTP API вызывают один сценарий `PlanSite` с одними нормами
и различаются только формой входа и выхода.

### 6.1. Командная строка

| Команда | Назначение |
|---|---|
| `green run ВХОД [ЕЩЁ…] [--profile P] [--set k=v] [--layer ГИС] [--inventory ВЕДОМОСТЬ] [--out ПАПКА]` | прогон: DXF или DWG, комплект, слои ГИС, переопределения параметров; печатает сводку и пути артефактов в JSON |
| `green audit ПЛАН --plantings ШАБЛОН [--trees …] [--shrubs …]` | нормоконтроль посадок проектировщика теми же правилами |
| `green inspect ФАЙЛ` | чтение без расчёта: классы, слои, единицы, пробелы чтения |
| `green verify ИСХОДНИК РЕЗУЛЬТАТ` | сверка исходных сущностей по отпечаткам |
| `green serve [--host] [--port] [--workers]` | HTTP API и веб-интерфейс |
| `green openapi --out ФАЙЛ` | выгрузка схемы OpenAPI |

Параметры задаются профилем (`--profile strict|barriers|no_utilities|review|shrubs`) и
переопределениями `--set`. Например, `--set spacing_m=6`, `--set crown_spacing=false`
(один шаг на все породы вместо шага по взрослым кронам), `--set sp42_edition=2026`,
`--set 'disabled_rules=[]'` (включает охранную зону газопровода по линии сети). Все параметры -
приложение D.

### 6.2. Веб-интерфейс

React-приложение (`frontend/`) ходит только в `/api/v1`. Шапка одна на всех экранах: слева
знак сервиса и путь «Прогоны / имя чертежа», на готовом прогоне - переключатель «План» и
«3D и фото»; справа «Модели растений», ссылка «API» на Swagger и переключатель темы (светлая
«бумага» и тёмная).

**Главная** (`/`) занимает один экран без прокрутки. Слева - что делает сервис, пример
результата (кадр плана с выносками отступов и фото той же улицы по 3D-кадру) и полоса «Как
это работает» из четырёх шагов: выбрать улицу, проверка норм, план, проверка и правка.
Справа форма «Новый прогон» и реестр «Прогоны». В форме - улица пилота из каталога или «Свой
чертёж подосновы» (DXF, DWG). Если каталог улиц на стенде не подключён, на его месте стоит
выбираемый вариант «Встроенный участок улицы Берзарина»: он отмечен, пока не выбран свой
файл, и кнопка запуска считает его. Под раскрытием «Параметры» - профиль норм, шаг посадки,
приёмы размещения галочками (добор газона, ряд кустарника, живая изгородь, подлесок,
кустарник на местах деревьев, группы на газоне, газоны, цветники, прикорневые барьеры),
остальные чертежи комплекта, перечётная ведомость, слои ГИС и JSON поверх профиля. Реестр
показывает состояние, чертёж, профиль, число посадок и время; законченный прогон удаляется
из строки с подтверждением.

**Рабочее место прогона** (`/runs/<id>`) - карта плана во весь экран и две сворачиваемые
панели по краям. Пока прогон идёт, над картой видны этап, его номер из общего числа и оценка
остатка времени. На карте подоснова, сети по видам, газон и покрытия, как их понял сервис,
посадки кронами по видам, отказы, места с барьером, газоны и зоны допустимости. Кнопки у
карты вписывают план в окно, меняют масштаб и включают режим «Править»; у идущего прогона
вместо правки - «Легенда».

- Левая панель: число посадок, три проверки результата («Отступы по нормам соблюдены»,
  «Исходные слои чертежа целы», «DXF совпадает с планом»), блок «Что проверить» (посадки на
  согласование, грунт по подписям), пояснение о деревьях исходного чертежа с недостаточным
  отступом до здания и кнопка их подсветки на плане. Статистика отклонённых вариантов
  новых посадок и мест с барьером перенесена в журнал «Как собран план» вместе со списком
  приёмов и решений подбора. Ниже строка газонов, внизу «Скачать план DXF» и «Отчёты и
  другие файлы». Вторая кнопка открывает окно «Отчёты и
  файлы прогона»: отчёт по посадкам, нормы CSV, пояснительная записка DOCX, отчёт
  распознавания, «Проверить распознавание объектов» и свёрнутые «Файлы расчёта».
- Правая панель без выбора посадки - вкладки «Посадки» (состав плана по видам с показом и
  подсветкой вида на карте), «Эффект» (баланс «было - стало» и оценка по шкале от 0 до 100 с разбором по
  слагаемым) и «Легенда» (условные обозначения и слои).
- Кнопка «Объекты чертежа» открывает панель уточнения классов: поиск слоя или блока, фильтр
  «Только требующие уточнения», подсветка выбранной группы на плане, «Применить и
  пересчитать». Если сервис распознал не все объекты однозначно
  (`semantic_assignments_complete: false`), на кнопке стоит знак предупреждения и подсказка
  «Не все объекты чертежа распознаны однозначно».

**Карточка посадки или отказа** заменяет правую панель по щелчку на карте:

- ближайшие нормы с выносками расстояний на карте;
- правило, пункт акта, таблица, цитата;
- раскрытие «О растении и его выборе»: почему этот вид, альтернативы, вклад в индекс;
- ссылка «Кадры посадки в 3D» на кадры этой посадки со всех сторон.

**Правка.** В режиме «Править» посадку тянут мышью или двигают клавишами Alt со стрелками, и
точка проверяется на ходу; Delete удаляет выбранную. Кнопка «Указать новое место на карте» в
карточке переносит посадку щелчком, без перетаскивания. Затем DXF пересобирается. Если
сервис правку не принял, посадка возвращается на место.

**Модели растений** - каталог того, как каждый из {{species}} видов нарисован на плане. На
главной это страница `/models`, на прогоне - окно поверх плана, чтобы не терять настроенный
вид.

**3D-вид** (`/runs/<id>/3d`). Слева карточка «В сцене» (деревья и кустарник плана,
существующие насаждения, здания) и панель «Снимки и фото». Справа «Пульт» с разделами:
«Посадки» (возраст посадок), «Время и сезон», «Слои плана», «Камера и качество», «Окружение»,
«Погода». Внизу кнопки «Общий вид», «Облёт», «Полёт», «Пешеход», «Схема» и «Без панелей».
«Схема» открывает основной план на нижнюю половину экрана: его можно приближать и
перетаскивать, маркер показывает положение и направление камеры. Щелчок переносит на
высоту глаз в выбранную точку с сохранением направления взгляда; внутри зданий и за
границей сцены переход запрещён. Стрелки двигают план, Enter переносит в его центр.

В карточке «В сцене» показано число существующих деревьев с недостаточным отступом до
здания; красный круг у дерева и подсказка при наведении объясняют расстояние и источник.
Проверяются только отдельные существующие деревья по геометрии сцены и базовому правилу
`R-BLD-TREE-001`, если оно подтверждено в правилах прогона. Это сравнение с требованием для
новой посадки, а не полный нормоконтроль существующих насаждений или назначение вырубки.
Радиус красного круга условный; подсветка отключается в разделе «Посадки» пульта. В панели
«Снимки и фото»:

- «Кадры» - галерея кадров улицы и посадки с автоматических ракурсов;
- «Снимок» - PNG текущего кадра, вариант «×2» вдвое крупнее для слайда;
- «Фото ИИ» - фото по кадру (разд. 5.9) с переключателями «фон и деревья» и «новые фасады» и
  окном промпта; фото открывается крупно, скачивается и удаляется.

### 6.3. HTTP API

`/api/v1`, JSON, ошибки в формате RFC 9457 (`application/problem+json`). Методы - разд. 7.
