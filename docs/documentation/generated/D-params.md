## Приложение D. Параметры профилей {#annex-params}

Все 113 параметров прогона (`PlanParams`). Значение - в профиле `strict`; в последнем столбце - отличия профилей `barriers`, `no_utilities`, `shrubs`. Любой параметр переопределяется в CLI (`--set ключ=значение`), в API и интерфейсе (JSON `overrides`); переопределения записываются в `run_manifest.json`. Сборка документации проверяет, что описан каждый параметр.

### Тип посадки и вид

| Параметр | Смысл | strict | Отличия |
|---|---|---|---|
| `planting_type` | тип основной посадки прогона: `tree` - деревья с кустарниковым ярусом, `shrub` - только кустарники | `tree` | shrubs: `shrub` |
| `species_code` | вид при `assortment_mode: single` | `tilia_cordata` | shrubs: `syringa_meyeri` |
| `assortment_mode` | `auto` - вид подбирает сервис; `given` - только виды и количества из `given_assortment`; `single` - один вид `species_code` | `auto` |  |
| `assortment_solver` | `auto` - целочисленная задача назначения видов с запасным жадным путём; `greedy` - сразу жадный | `auto` |  |
| `given_assortment` | заданный ассортимент: код вида -> число | `{}` |  |
| `assortment_weights` | веса факторов пригодности вида месту: условия места, функция, декоративность, долговечность, уход, практика пилота, категория насаждений, тень | `site: 0.3, function: 0.2, decor: 0.15, longevity: 0.15, care: 0.1, pilot: 0.1, category: 0.2, shade: 0.15` |  |
| `region_hardiness_zone` | зона зимостойкости региона (Москва 4b-5a): вид с зоной выше не допускается | `4` |  |
| `salt_zone_m` | ширина полосы у проезжей части, где учитывается солеустойчивость вида (реагенты), м; проектный параметр | `5.0` |  |
| `max_height_under_lines_m` | предельная высота растения в охранной зоне ВЛ, м; проектный параметр: ПП РФ № 160, п. 10 «в» требует согласования посадки, высоту не задаёт | `4.0` |  |
| `territory` | тип территории по 369-ПП; решает допустимость видов группы III | `green_fund` |  |
| `planting_category` | категория насаждений по МГСН 1.02-02, табл. В.6: ассортимент улиц, дворов, парков | `streets` |  |
| `allergen_act_priority` | `true` - при расхождении актов решает акт, называющий вид: вид, рекомендованный МГСН 1.02-02, табл. В.6, допускается, аллергенность снижает оценку; `false` - запрет массовых аллергенов по 743-ПП, п. 3.6.18 | `true` |  |
| `condition_penalty` | снижение оценки вида с условием посадки или слабого аллергена (оценка 0-1): при равных квотах берётся вид без обязательств | `0.2` |  |
