# Примеры входа и выхода

Готовый прогон сервиса, чтобы посмотреть результат без запуска: вход - DXF, выход - DXF со
слоями `GREEN_*` и файлы интерпретаций. Раздел 7.2 ТЗ: «примеры входных/выходных DXF».

## Фрагмент улицы Берзарина

Вход: [`src/green/infrastructure/cad/samples/berzarina_fragment.dxf`](../src/green/infrastructure/cad/samples/berzarina_fragment.dxf),
окно 300 x 140 м настоящего чертежа пилота ДПиООС: геоподоснова и сети, 125 слоёв, 12 694
сущности. Тот же фрагмент считает кнопка «Запустить на встроенном участке» в веб-интерфейсе.

Выход - [`berzarina-fragment/`](berzarina-fragment/), тот же расчёт, что даёт образ Docker
командой

```bash
docker run --rm -v "$PWD/src/green/infrastructure/cad/samples:/in:ro"   -v "$PWD/examples/berzarina-fragment:/out" --entrypoint green green:latest   run /in/berzarina_fragment.dxf --profile strict --out /out
```

Прогон 29.09.2026 кодом с шагом деревьев по взрослым кронам (docs/notes/39), локально
через `uv run green run`: 52 с, 1278 посадок (1260 допустимы, 18 требуют согласования), из
них 80 деревьев; 32 отказа, 9 газонов на 1749 м². `verify.json`: все 12 694 исходные
сущности без изменений, новое только на слоях `GREEN_*`. Грунт под ямой подтверждён
замкнутыми контурами у 478 посадок, у 800 выведен по подписям, поэтому сводка прогона
требует проверки покрытия человеком (`surface_inference_review_required`).

| Файл | Что это |
|---|---|
| `result.dxf` | копия входа в его версии и единицах; план на слоях `GREEN_*`: деревья и кустарник блоками видов с атрибутами (`NPA` - правило, акт и пункт), отказы у сетей, зоны, газоны штриховкой, легенда правил и ведомость элементов озеленения (`GREEN_SCHEDULE`, ГОСТ 21.508-2020, форма 9) |
| `report.html` | отчёт интерпретаций для человека: каждая посадка и каждый отказ с пунктом акта и дословной цитатой |
| `interpretations.md` | то же в Markdown |
| `plantings.csv` | посадка на строку: вид, координаты, вердикт, место, объяснение |
| `planting_schedule.csv` | ведомость посадочного материала |
| `quality.json` | индекс качества плана со слагаемыми и баланс «было - стало» по участку |
| `verify.json` | проверка целостности: исходные сущности не изменены, новое только на `GREEN_*` |
| `run_manifest.json` | параметры прогона, версии, отпечатки входа и свода норм |
| `rules.json` | свод норм прогона: правило, расстояние, способ измерения, акт, пункт и цитата |
| `assortment.json` | состав плана по видам и основания подбора |
| `renders/` | бонус ТЗ: снимки 3D-вида этого прогона (страница «3D» веб-интерфейса) - общий вид в 10 лет после посадки, взрослые кроны сверху и вид с газона в 25 лет |
| `interpretations.csv.zip` | строка на пару «решение - правило» для каждой посадки и отказа (30 925 строк, около 32 МБ без сжатия) |

Проверка выхода без CAD: `uv run green verify src/green/infrastructure/cad/samples/berzarina_fragment.dxf examples/berzarina-fragment/result.dxf`.

### Проверка в CAD под Linux

`berzarina-fragment/cad/` - снимки LibreCAD 2.2.0.2 под Ubuntu 26.04 из контейнера
`docker/cadcheck` (раздел 5.6 документации), 29.09.2026. Проверялись `result.dxf` строгого
профиля, посчитанные образом сервиса с кодом коммита `6d0e847` (номер позиции у посадки,
ведомость и легенда справа от плана). Это более новый прогон, чем `result.dxf` этой папки: во
встроенном фрагменте 1205 посадок - 82 дерева и 1123 куста.

| Файл | Что это |
|---|---|
| `librecad-result.png` | фрагмент Берзарина: вид вписан по слоям `GREEN_*`, включены все слои - посадки поверх подосновы, правее плана ведомость и легенда |
| `librecad-layers.png` | тот же вид, список слоёв с фильтром `GREEN`: 11 слоёв результата отдельно от исходных |
| `librecad-schedule.png` | ведомость элементов озеленения крупно: позиции, количества и размеры читаются, русские слова LibreCAD рисует значками |
| `kustanayskaya-librecad.png` | Кустанайская улица (33 МБ, LibreCAD открыл за 397 с): вид по слоям `GREEN_*`, включены только слои результата - 210 деревьев, 794 куста, отказы у сетей красным; ведомость и легенда справа сверху |

## Полные улицы пилота

Выходы 19 улиц каталога в репозиторий не кладутся: это чертежи заказчика (геоподоснова
Мосгеотреста) размером до сотен мегабайт. Итоги по каждой улице - приложение B документации
(`docs/documentation/green-documentation.pdf`). Любую улицу каталога можно посчитать в
веб-интерфейсе («Улица пилота») или той же командой, что считала приложение B (датасет
смонтирован в `./dataset`):

```bash
docker compose run --rm -v "$PWD/tools:/app/tools:ro" \
  -v "$PWD/out/street-runs:/app/out/street-runs" --entrypoint python \
  api tools/street_runs.py --only 18 --catalog /dataset/streets_oda --profile strict
```
