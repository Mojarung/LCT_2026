# Материалы аудита и нормативного анализа (agy_checkup)

Папка сформирована в рамках независимого аудита решения кейса ДПиООС (ЛЦТ 2026) на соответствие техническому заданию и **10 актуальным нормативно-правовым актам** (выгруженным в `lct_dataset/Датасет/нормативные акты актуальные/cntd_parser/Docs as HTML/`).

---

## Навигация по материалам

| Файл | Описание | Для кого |
|---|---|---|
| 📄 [`review.md`](review.md) | **Детальный аудит и код-ревью** проекта `LCT_2026`: сильные стороны, соответствие ТЗ, 5 критических нормативных пробелов и план их устранения. | Для всей команды и тимлида |
| 🗄️ [`norms_extended.json`](norms_extended.json) | **Расширенный нормативный справочник в JSON**: сводная база отступов, коэффициентов прикорневых барьеров, черных списков (369-ПП), белых списков (515-ПП) и ГОСТ 21.508-2020. | Для разработчиков алгоритма и правил |
| 📖 [`norms_structure.md`](norms_structure.md) | **Описание схемы `norms_extended.json`** с примерами и пошаговой инструкцией переноса полей в `config/acts.yaml`, `config/rules.yaml` и `config/species.yaml`. | Для тех, кто правит конфиги норм |
| 📋 [`plan_and_requirements.md`](plan_and_requirements.md) | **Целевая спецификация требований к алгоритмическому ядру**: этапы пайплайна, математическая постановка, CAD-выгрузка по ГОСТ и требования к защите. | Для отчета, презентации и BPMN |

---

## Ключевой вывод аудита

Проект команды `green` обладает **высоким качеством архитектуры (9.0 / 10)** и всеми базовыми возможностями для победы. Внедрение недостающих ссылок на **ППМ № 515-ПП** (официальный каталог Москвы), режима **прикорневых барьеров** (СП 42 табл. 9.1 Прим. 5) и оформления по **ГОСТ 21.508-2020** снимет все возможные претензии экспертов ДПиООС.
