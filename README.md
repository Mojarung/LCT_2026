# green

Сервис автопроектирования озеленения улиц для кейса ДПиООС (ЛЦТ 2026): DXF или DWG с подосновой и сетями -> ограничения по нормам -> план посадок на отдельных слоях `GREEN_*` -> DXF и файл объяснений со ссылками на правила и пункты НПА. На каждом прогоне сравниваются экспортируемые исходные DXF-сущности до и после записи; предел этой проверки описан в [алгоритме](docs/algorithm.md#11-проверка-целостности).

В `main` незагруженные XREF не собираются автоматически и ещё не блокируют построение плана. До использования результата нужно собрать полный пакет зависимых чертежей: иначе сети могут быть потеряны. Защита от неполного пакета остаётся открытой задачей в [плане](docs/plan.md).

```bash
uv sync
uv run green run путь/к/файлу.dxf --profile strict
uv run green serve                  # OpenAPI: http://127.0.0.1:8000/docs
docker compose up --build           # то же в контейнере, API на :8000
```

Команды проверки проекта: `uv run ruff check src tests`, `uv run ruff format --check src tests`, `uv run ty check src`, `uv run lint-imports`, `uv run pytest`.
