# Контекст датасета для исследовательского промпта

Первоначальный 95-строчный листинг от 15.09.2026 перенесён в [карту данных](../../docs/notes/08-dataset-map.md); исходная версия сохранена в Git. Для актуального контекста прикладывайте эту карту и [массовый DWG-скан](../../docs/notes/05-dwg-scan.md), а для конкретного алгоритма — [описание текущего кода](../../docs/algorithm.md).

В пилоте 20 папок улиц, входы обычно в `Исходные данные`, проектные эталоны — в `Проектное решение`. Локально подтверждён один исходный DXF АСУ ОДХ в 3-й Парковой; остальные настоящие CAD-входы преимущественно DWG с XREF. По массовому скану 819 настоящих DWG, 749 успешно сконвертированы по исходным Windows-путям, 70 отказали из-за длины пути. Отдельный файл проектировщика не доказывает юридическую или почвенную пригодность его посадок.
